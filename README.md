# AccessiAI - AI-Powered Website Accessibility Scanner\n\nAccessiAI is a SaaS web application that helps small and medium websites check accessibility compliance using AI-powered analysis against WCAG 2.1 AA guidelines.\n\n## Features\n\n- **AI-Powered Scanning**: Uses OpenAI GPT-4 to analyze website HTML and identify accessibility issues\n- **WCAG 2.1 AA Compliance**: Checks against the latest Web Content Accessibility Guidelines\n- **Detailed Reports**: Provides comprehensive reports with severity levels, WCAG references, and actionable recommendations\n- **PDF Export**: Export accessibility reports as PDFs for sharing with teams or clients\n- **User Authentication**: Secure signup/login with Supabase\n- **Subscription Management**: Free tier (1 scan) and Pro tier (unlimited scans) with Stripe integration\n- **Clean UI**: Modern, responsive interface built with TailwindCSS\n\n## Tech Stack\n\n- **Frontend**: Next.js 14, React, TypeScript, TailwindCSS\n- **Backend**: Next.js API Routes\n- **Database**: Supabase (PostgreSQL)\n- **Authentication**: Supabase Auth\n- **Payments**: Stripe\n- **AI**: OpenAI GPT-4\n- **Deployment**: Vercel\n\n## Getting Started\n\n### Prerequisites\n\n- Node.js 18+ and npm\n- Supabase account\n- OpenAI API key\n- Stripe account (for payments)\n\n### Installation\n\n1. Clone the repository:\n   ```bash\n   git clone <repository-url>\n   cd accessiai\n   ```\n\n2. Install dependencies:\n   ```bash\n   npm install\n   ```\n\n3. Set up environment variables:\n   Copy `.env.example` to `.env.local` and fill in your values:\n   ```bash\n   cp .env.example .env.local\n   ```\n\n   Required environment variables:\n   ```env\n   # Supabase Configuration\n   NEXT_PUBLIC_SUPABASE_URL=your_supabase_project_url\n   NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key\n   SUPABASE_SERVICE_ROLE_KEY=your_supabase_service_role_key\n   \n   # OpenAI Configuration\n   OPENAI_API_KEY=your_openai_api_key\n   \n   # Stripe Configuration\n   STRIPE_SECRET_KEY=your_stripe_secret_key\n   NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=your_stripe_publishable_key\n   STRIPE_WEBHOOK_SECRET=your_stripe_webhook_secret\n   STRIPE_PRO_PRICE_ID=your_stripe_pro_price_id\n   \n   # App Configuration\n   NEXT_PUBLIC_APP_URL=http://localhost:3000\n   ```\n\n4. Set up Supabase database:\n   Run the SQL commands from `supabase-schema.sql` in your Supabase SQL editor.\n\n5. Set up Stripe:\n   - Create a product and price in your Stripe dashboard\n   - Set up webhook endpoint: `https://your-domain.com/api/webhooks/stripe`\n   - Add the webhook secret to your environment variables\n\n6. Run the development server:\n   ```bash\n   npm run dev\n   ```\n\n7. Open [http://localhost:3000](http://localhost:3000) in your browser.\n\n## Deployment\n\n### Deploy to Vercel\n\n1. Push your code to GitHub\n2. Connect your repository to Vercel\n3. Add environment variables in Vercel dashboard\n4. Deploy!\n\n### Environment Variables for Production\n\nMake sure to set all the environment variables in your Vercel dashboard:\n- All Supabase variables\n- OpenAI API key\n- Stripe keys and webhook secret\n- Update `NEXT_PUBLIC_APP_URL` to your production domain\n\n## Usage\n\n1. **Sign Up**: Create an account with email and password\n2. **Dashboard**: Enter a website URL and click "Scan Now"\n3. **View Report**: Once scanning is complete, view the detailed accessibility report\n4. **Export PDF**: Download the report as a PDF for sharing\n5. **Upgrade**: Free users get 1 scan per month. Upgrade to Pro for unlimited scans.\n\n## API Endpoints\n\n- `POST /api/scan` - Scan a website for accessibility issues\n- `POST /api/checkout` - Create Stripe checkout session\n- `POST /api/webhooks/stripe` - Handle Stripe webhooks\n\n## Database Schema\n\n### Profiles Table\n- `id` (UUID, Primary Key)\n- `email` (Text)\n- `full_name` (Text)\n- `subscription_tier` (Text: 
free | pro)\n- `scans_used` (Integer)\n- `scans_limit` (Integer)\n- `stripe_customer_id` (Text)\n- `created_at` (Timestamp)\n- `updated_at` (Timestamp)\n\n### Scans Table\n- `id` (UUID, Primary Key)\n- `user_id` (UUID, Foreign Key)\n- `url` (Text)\n- `status` (Text: pending | processing | completed | failed)\n- `issues` (JSONB)\n- `report_data` (JSONB)\n- `created_at` (Timestamp)\n- `completed_at` (Timestamp)\n\n## Contributing\n\n1.
